# NEXUS

Личная система знаний и продуктивности: иерархическая база знаний (папки → подпапки → темы без ограничения глубины), заметки с богатым редактором, недельный планер и задачи.

Работает **local-first**: все данные хранятся в браузере (IndexedDB) и сохраняются после перезагрузки страницы. Сервер и база данных не нужны.

## Быстрый старт

Нужен **Node.js 20.9+** (рекомендуется 22 LTS).

```bash
git clone https://github.com/samilualiulla-dev/NEXUS.git
cd NEXUS
npm install
npm run dev
```

Откройте http://localhost:3000.

Production-сборка:

```bash
npm run build
npm start
```

## Возможности

**Знания**
- Папки, подпапки и заметки на любой глубине. Никаких жёстко заданных предметов.
- Переименование, удаление (вместе с содержимым), дублирование всего поддерева, перемещение.
- Drag & drop в боковой панели и на странице папки: верх/низ строки — поставить до/после, центр папки — положить внутрь. На телефоне то же самое через меню «⋯» → «Переместить в…» / «Выше» / «Ниже».
- У каждой папки и заметки своя страница (`/n/<id>`), хлебные крошки, иконка-эмодзи.
- Файлы можно прикреплять и к папкам, и к заметкам.

**Заметки**
- Заголовки, списки, чек-листы, таблицы, изображения (вставка через Ctrl+V или перетаскиванием), ссылки, блоки кода, цитаты, формулы KaTeX (в строке и отдельной строкой).
- Markdown-сокращения: `#`, `##`, `-`, `1.`, `[ ]`, `` ``` ``, `>`.
- Автосохранение (≈0,6 с после последнего изменения и при уходе со страницы).
- Статусы: Важно / Повторить / Понятно / В процессе.

**Планер**
- Виды «день», «неделя» и «месяц»; неделя начинается с понедельника.
- Мини-календарь для выбора любой даты.
- Дела со временем начала и окончания, приоритетом, описанием, заметками и отметкой о выполнении.
- Задачи со сроком тоже видны в планере.
- Перетаскивание дел и задач между днями. В режиме «день» — шкала времени: клик по часу создаёт дело.

**Задачи**
- Сроки, приоритеты, категории, привязка к предмету или заметке.
- Фильтры: сегодня, предстоящие, просроченные, выполненные.
- Панель прогресса: общий процент, прогресс по категориям, задачи, выполненные за неделю.

**Поиск** (`Ctrl+K` / `⌘K`)
- Ищет по папкам, заметкам (включая их **текст**), задачам и событиям.
- Фильтр заметок по статусам.

**Прочее**
- Тёмная и светлая темы.
- Адаптивная вёрстка для ПК, планшета и телефона.
- Резервная копия: ⚙ → «Скачать копию (.json)» / «Восстановить из файла».

## Настройка

`src/config/app.ts`: название приложения (`name`), первый день недели и часы, которые показывает дневной вид.

## Структура проекта

```
src/
  app/                  страницы (App Router)
    page.tsx            главная (дашборд)
    n/[id]/page.tsx     страница папки или заметки
    planner/page.tsx    планер
    tasks/page.tsx      задачи
  config/app.ts         название и общие настройки
  lib/                  данные и логика без UI
    db.ts               схема IndexedDB (Dexie) и типы
    tree.ts             операции с деревом: создать/переместить/дублировать/удалить
    tasks.ts, events.ts CRUD задач и событий планера
    search.ts           глобальный поиск
    backup.ts           экспорт/импорт JSON
    files.ts            вложения и изображения
  components/
    shell/              каркас: боковая панель, настройки
    knowledge/          дерево, страницы папок и заметок, DnD, теги
    editor/             редактор TipTap и панель инструментов
    planner/            виды день/неделя/месяц, мини-календарь, диалог дела
    tasks/              строка и диалог задачи
    search/             палитра поиска
    ui/                 базовые компоненты (кнопки, модалки, меню)
```

## Как устроены данные

Папки и заметки лежат в одной таблице `nodes` со ссылкой `parentId`, поэтому глубина вложенности не ограничена. Текст заметки хранится отдельно: `docs` (JSON редактора) и `texts` (простой текст для поиска). Так дерево остаётся лёгким. Таблицы `tasks`, `events` и `attachments` описаны в `src/lib/db.ts`.

## Как подключить серверную БД позже

Интерфейс работает с данными только через функции из `src/lib/*` (`createNode`, `moveNode`, `createTask`, `updateEvent`, …) и через живые запросы `useLiveQuery`. Для перехода на сервер (например, PostgreSQL + Prisma или Supabase):

1. Создайте API (Next.js Route Handlers в `src/app/api/...` или Supabase) с теми же сущностями, что и в `src/lib/db.ts`.
2. Перепишите функции в `src/lib/tree.ts`, `tasks.ts`, `events.ts`, `files.ts` так, чтобы они вызывали API. Сигнатуры можно оставить прежними.
3. Замените `useLiveQuery(...)` на свой хук загрузки данных (например, TanStack Query) с инвалидацией после изменений.
4. Перенесите данные: скачайте копию в ⚙ → «Скачать копию» и импортируйте JSON на сервер. Формат файла — массивы `nodes`, `docs`, `texts`, `tasks`, `events`, `attachments`.

Есть и вариант проще: оставить IndexedDB основным хранилищем и добавить фоновую синхронизацию с сервером.
